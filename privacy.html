Политика обработки персональных данных

Настоящая политика определяет порядок обработки персональных данных пользователей сайта «Открытые Пространства» при заполнении формы заявки.

1. Какие данные собираются

Имя, номер телефона, тип мероприятия и текст комментария, указанные пользователем в форме заявки.

2. Цель обработки

Данные используются исключительно для связи с пользователем по его обращению и подготовки расчёта стоимости мероприятия. Третьим лицам данные не передаются, за исключением технического сервиса передачи заявок оператору.

3. Хранение и защита

Данные хранятся не дольше, чем необходимо для обработки обращения, и не используются для рассылок без отдельного согласия пользователя.

4. Согласие

Отправляя форму на сайте, пользователь даёт согласие на обработку указанных персональных данных в целях, описанных выше. Согласие может быть отозвано по контактам ниже.

5. Контакты
